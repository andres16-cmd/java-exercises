# java-exercises

University exercises and practice problems implemented in Java.

## Structure

The repository is organized by practice:

```text
java-exercises/
├── README.md
├── lib/
│   └── PaqueteLectura.jar
├── Practica_1/
│   ├── Ejercicio_1.java
│   ├── Ejercicio_2.java
│   └── ...
├── Practica_2/
│   └── ...
└── ...
```

New practices will be added as the course progresses.

## PaqueteLectura

The exercises use `PaqueteLectura.jar`, located in the `lib/` directory.

It provides classes such as:

```java
import PaqueteLectura.Lector;
import PaqueteLectura.GeneradorAleatorio;
```

## Requirements

* Java JDK
* A Java-compatible IDE
* `PaqueteLectura.jar`

## Setup

To run exercises that use `PaqueteLectura`, add:

```text
lib/PaqueteLectura.jar
```

as a dependency of your Java project.
